Saturn Tracktor для Windows 11 x64. Gevork Saturn.

Скачайте `SaturnTracktor-Setup-1.0.2.exe`, запустите и подтвердите запрос Windows. Установщик включает приложение, .NET, виртуальный аудиодрайвер, исходники и лицензии. Если отсутствует WebView2, он будет загружен с серверов Microsoft.

Установка в `C:\Program Files\SaturnTracktor`, ярлыки на рабочем столе и в меню «Пуск», удаление через список приложений Windows. Компактный режим: 900 × 270 при масштабе 150%.

EXE и установщик не имеют сертификата подписи кода. Gevork Saturn указан в метаданных. Драйвер и его helper сохраняют исходные подписи Microsoft/FxSound.

Программа и системный звук проверены на компьютере автора. Чистая Windows без драйвера и WebView2 отдельно не проверялась. См. README о возможностях, проверках и ограничениях. `SaturnTracktor-source.zip` содержит соответствующий исходный код, включая компоненты драйвера. `SHA256SUMS.txt` содержит контрольные суммы файлов.
